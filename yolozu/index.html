YOLOZU

Compare vision models

Evaluate model predictions on the same data and settings. YOLOZU checks the prediction files and produces reports while you keep your existing training and inference tools.

Start with the docs GitHub repository PyPI package Quickstart
Detection Instance segmentation Keypoints Monocular depth 6DoF pose

Make the comparison consistent

Different preprocessing or scoring settings can change results. YOLOZU records those settings so you can check what changed.

  • A shared format for prediction files
  • Recorded export and evaluation settings
  • Reports and demo images to inspect

Use cases

What you can check

Compare model results

Use the same dataset and scoring rules for outputs from different tools.

Catch input errors

Check prediction files for missing fields and format errors before scoring.

Check changes

Compare reports before and after a model or runtime update.

Scope

What is included

The core is prediction validation and evaluation. Training, adapters, benchmarks, and research features have separate maturity labels. YOLOZU runs in your environment; it does not include hosted training, inference, or production deployment.

Quickstart

Try the demo

Check the installation and generate a segmentation report with images.

python3 -m pip install -U yolozu
yolozu doctor --explain
yolozu demo instance-seg --run-dir reports/quickstart_instance_seg --progress
  • Report: reports/quickstart_instance_seg/instance_seg_demo_report.json
  • Images: reports/quickstart_instance_seg/overlays/*.png
  • Next-step help: yolozu guide or yolozu guide --goal evaluate

Evaluation flow

From predictions to a report

1. Export Save model outputs in the shared prediction format.
2. Validate Check the files before scoring.
3. Evaluate Score with fixed evaluation settings.
4. Compare Inspect the reports and images.

# Quiz Template (JA/EN)

このテンプレートは、`education/quiz_template_skeleton.html` をコピーして、任意テーマのクイズページを作成するためのガイドです。既存のクイズと同じ回答、採点、解説表示を使えます。

## 使い方（最短）

1. `education/quiz_template_skeleton.html` をコピー

   - 例: `education/quiz_my_topic.html`

2. ページ上部の `DRILL_SETTINGS` を編集（ブランド関連は固定）

   - `SKILL_NAME`（スキル名/テーマ名）
   - `SKILL_SUBTITLE`（サブタイトル）
   - `LEARNING_MODE_DEFAULT`（true/false）

   共通の学習方針やゴールはハブページに一度だけ記載します。個別ページに `GOAL_DESCRIPTION`、ゴール文、学習方法を反復して表示しません。

   注: ブランド関連キー（`BRAND_NAME`, `BRAND_LOGO`, `BRAND_URL`）は運用方針として `ToppyMicroServices` 固定です。テンプレートに残っていても変更しないでください。不要なら新規ページ作成時に削除しても動作に支障はありません。

3. `#questions` に設問を追加

   - 最低1問、`<article class="q card" ...>` をコピーして増やしてください。
   - `data-id` を `Q1`, `Q2`... と一意に振る。
   - `data-type` と `data-answer` を設定（下記参照）。

4. 動作確認し、必要に応じてリンク（言語切替など）を調整

個別ページでは Cheat Sheet、重要キーワード一覧、初心者向けの見方を反復しません。設問ごとのヒントは任意で用意できますが、初期状態では閉じ、学習者が必要なときだけ開く形にします。

## 設問タイプと属性

共通: `data-id="Qn"`（一意）

- **任意ヒント**
  - `<article>` に `data-hint="..."` を付けると、「ヒントを見る」ボタンが表示されます。
  - ヒントは比較する軸、確認すべき条件、考える順序に限定します。
  - 正解の選択肢、正誤、解説の要約を先に示してはいけません。

- **Multiple Choice（単一選択）**
  - `data-type="mc"`
  - `data-answer="b"`（正答のキー）
  - 選択肢は `<label class="choice"><input type="radio" name="Qn" value="a"> A. ...</label>` のように a,b,c...

- **Multi Select（複数選択）**
  - `data-type="ms"`
  - `data-answer="a,c"`（カンマ区切り）
  - `<input type="checkbox" ... value="a">`
  - 選択後に「回答を確定」を押した時点で採点し、解説を表示する。

- **Short Text（テキスト: 厳密一致 or 正規表現）**
  - `data-type="text"`
  - 厳密一致: `data-answer="answer"`, `data-eval="exact"`（省略可）
  - 正規表現: `data-eval="regex"`
  - 入力後に「回答を確定」を押すか Enter を押した時点で採点し、解説を表示する。

## 解説を書く

- 各 `<article class="q card" ...>` 内の `<div class="explain">...</div>` に、設問ごとの根拠を記述します。
- 解説は回答後にだけ表示します。選択前の選択肢の下に、正誤の理由や要約を表示しません。
- HTMLに書いた説明を正本とします。実行時の自動補完で不足を埋める前提にはしません。

## クイズ作成ポリシー（必須）

教材全体の狙いはハブページで説明します。個別ページでは、設問とその根拠に集中します。

### 出題ポリシー

- コマンドやオプション名の暗記だけを問わない。
- 定義、役割、適用条件、境界、失敗時の意味を区別できる設問にする。
- 問題文だけでも解答できるようにする。補助ヒントは閉じた状態で設問内に置き、正解や選択肢ごとの根拠を先出ししない。
- 正解だけが問題文をほぼ復唱する、正解だけが不自然に長い、誤答だけが別カテゴリになる構成を避ける。選択肢は同じ粒度と形式で比較できるようにする。
- Multi-Select で全選択肢を正解にしない。少なくとも1つは、同じ粒度で比較できる妥当な誤答を含める。
- 同じページで正解位置を一つの文字に偏らせない。内容以外から正解を推測できる規則性を作らない。
- URLやテーマの追加があった場合は **10問**。
- 大きいテーマは **25問**。

### 解説ポリシー

解説は、正誤を生む定義、条件、仕様上の根拠を直接書きます。

- Multiple Choice / Multi Select は、正解を含む各選択肢について、その選択肢固有の理由を書く。
  - `正解です`、`定義に合致します`、`別の概念です` のような一般論だけでは不十分。
  - どの語、条件、責務、境界が一致または不一致なのかを明示する。
- Short Text は、受理する答えの範囲と、その根拠を説明する。
- `問題を出した背景`、`用語`、`実務での機会`、`関連`などの定型見出しは必須ではない。必要な情報だけを自然な順序で書く。
- 出題意図、学習方法、一般的な注意を全問で反復しない。
- 太字は必要な箇所の強調にだけ使い、キーワード一覧を作るためには使わない。
- 問題/解説領域は、テンプレのMarkdown処理（例: `**bold**`, `` `code` ``）が適切に反映される前提で書く。
  - 使う記法は、テンプレが処理できる範囲に留め、HTMLを壊す書き方は避ける。

HTMLに記述した解説は次のコマンドで検査します。ランタイムによる補完は検査対象に含まれません。

```bash
python3 scripts/quiz_policy_check.py --strict --paths education/quiz_example.html
```

## 言語切替

- `quiz_template_skeleton.html` 自体は単一言語前提です（`<html lang="en">`）。
- 日本語版/英語版をペアで作る場合は、`quiz_finance_terms.html` / `quiz_finance_terms_en.html` のようにファイルを分け、ヘッダーに言語切替リンクを追加する形を推奨します。
